Curtis Tech Solutions — Audio Plugins (VST3)
=============================================

Contents: Strata, VoxNote, Intone, Ducker, Frisson, Verdant (one .vst3 bundle each).

Install by copying the .vst3 folders into your VST3 plugin folder, then
rescan plugins in your DAW.

  Windows : C:\Program Files\Common Files\VST3\
  macOS   : ~/Library/Audio/Plug-Ins/VST3/       (or /Library/Audio/Plug-Ins/VST3/)
  Linux   : ~/.vst3/

macOS: if the build was not notarised (see VERSION.txt / the release notes),
clear the download quarantine once after copying:

  xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/*.vst3

VoxNote outputs MIDI from an audio effect. In Ableton, Reaper and Bitwig route
it to an instrument as host MIDI. In FL Studio (whose VST3 wrapper often drops
an effect's MIDI) and Logic / GarageBand (which can't route it), use VoxNote's
"MIDI out" card to send the notes straight to a MIDI port instead:
  Windows      : create a port in loopMIDI (tobias-erichsen.de), pick it in
                 VoxNote, enable it as an input in FL's Options > MIDI Settings
                 and select the instrument's channel.
  macOS / Linux: pick "VoxNote (virtual port)" and use it as a MIDI input.
